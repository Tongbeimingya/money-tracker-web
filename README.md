# 💰 Money Tracker Web

一个简洁易用的个人记账Web应用，支持预算管理、分类统计、多周期记录。

## ✨ 特性

- 📊 **预算管理**：设置月度预算目标，实时追踪支出
- 🏷️ **分类管理**：支持大分类和小分类，灵活组织你的开支
- 📅 **周期管理**：支持月度周期和自定义周期
- 💾 **本地存储**：数据保存在浏览器本地，隐私安全
- 📱 **响应式设计**：手机、平板、电脑都能完美使用
- 🎨 **美观界面**：iOS风格设计，简洁清爽

## 🚀 在线使用

访问：https://你的用户名.github.io/money-tracker-web/

## 📦 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📖 使用说明

1. **设置预算**：点击右上角⚙️设置本月生活费目标
2. **添加大分类**：创建"刚性支出"、"弹性支出"等大类
3. **添加小分类**：在大分类下添加具体的开支类别（如房租、餐饮）
4. **记录支出**：点击分类卡片，添加具体的支出记录

## 📱 手机使用

1. 在手机浏览器打开网页
2. 点击浏览器菜单 → "添加到主屏幕"
3. 就像原生App一样使用！

## 💡 技术栈

- Vue 3
- Vue Router
- Vite
- LocalStorage API
